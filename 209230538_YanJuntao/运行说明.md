储能231 · 严军涛 · 209230538

## 运行环境

- MATLAB R2026a、Optimization Toolbox、MATPOWER、YALMIP。
- 将 ESS-Course-Materials 的 `interactive/` 和 `cases/` 添加到 MATLAB 路径。
- 按任务一、二、三、第二周的顺序运行各实时脚本，即可生成两周汇总数据。

## 第二周任务四

打开 `YanJuntao_209230538_Week2.mlx` 并点击“全部运行”，或在 MATLAB 当前文件夹运行同名 `.m`。

程序包含完整的五档储能选址定容 MILP 模型、Big-M 线性化、8 组参数灵敏度试验、MATPOWER 交流潮流回代、运行约束检查和原生图导出。模型与绘图函数均在同一程序文件内。任务四使用 MATLAB 自带 `intlinprog`。

输出文件：

- `result_summary.mat`：标准 `Result` 六字段及两周完整 `result_summary`；`Opt_Sites` 是候选位置序号，`Candidate_Buses` 保存实际母线映射。
- `Week2_Planning_raw.mat`：基准规划与全部灵敏度原始数据、求解状态和核验结果。
- `Week2_Configuration.csv`、`Week2_Costs.csv`、`Week2_Sensitivity.csv`：配置、费用及灵敏度数值表。
- `Fig_Week2_209230538`、`Fig_Week2_Voltage_209230538`、`Fig_Week2_Operation_209230538`、`Fig_Week2_Sensitivity_209230538`、`Fig_Week2_Network_209230538`：每幅均导出白底 600 dpi PNG、原生矢量 PDF 和可编辑 FIG。
- `YanJuntao_209230538_Report.pdf`：含任务一至四的两周完整报告，共 18 页。

## 第一周

任务一、二、三各有同名 MLX 与 M 文件。任务三主结果为目标 C，并包含同场景 A/B/C 数值比较。

任务三优先使用 MOSEK/Gurobi；未安装时使用 `solver_support/` 中的 Clarabel 接口，通过锥松弛对偶下界、整数可行解上界及必要的分支定界核验。接口依赖 Python、SciPy 和 Clarabel，可用 `python3 -m pip install scipy clarabel` 安装。若 MATLAB 未找到 Python，可设置 `ESS_PYTHON` 为所需 Python 可执行文件路径。
